# Responsive Text Layout Using HTML & CSS

## 📌 Project Overview
This project demonstrates a responsive layout created using HTML5 and CSS3. It contains three text sections displaying the same passage, arranged using Flexbox and adjusted for different screen sizes using CSS Media Queries.

## 🚀 Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## ✨ Features
- Three text content sections arranged horizontally on larger screens.
- Responsive layout using Flexbox.
- Vertical alignment on smaller screen sizes.
- Different heights and font sizes based on screen width.
- CSS media queries for responsive design.
- Basic styling with borders, padding, and spacing.

## 📱 Responsive Breakpoints
The layout adjusts according to the following screen widths:

| Screen Width | Responsive Behavior |
|---|---|
| 1075px | Content height changes to 300px |
| 778px | Sections stack vertically |
| 649px | Content height changes to 140px |
| 567px | Content height changes to 170px |
| 451px | Font size changes to small |
| 379px | Font size remains small |
